# Create schedules for batch audience evaluation

Control when your audiences run with flexible batch schedules in Adobe Experience Platform. Move beyond the once-daily default, scale up to 10,000 audiences per org, and choose daily, weekly, monthly, or multiple-times-a-day cadences. Learn how to create custom schedules, monitor segmentation jobs, and manage credits — all from the new Evaluation tab in Audiences.
